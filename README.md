A faster drop-in for makefun-site 1.0.0: it renders the same static sites byte-for-byte in roughly 3.5× less CPU time, using a fused single-pass Markdown renderer and templates compiled to JavaScript functions.

## Run it

```sh
node main.ts
```

`main.ts` reads every case from `$MAKEFUN_INPUT_DIR` (default `/input/cases.json`), answers each one with `run()` from `solve.js`, and writes the answers to `$MAKEFUN_OUTPUT_DIR/answers.json`.
